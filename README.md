The entry is one tombstone epitaph, the stone complaining about its own carving bill:

> Carved at 8¢/glyph. Should've used vector graphics.

The last regret is a graphics-format optimisation, and the stone is still pricing itself per glyph.

## Run

```
node main.ts
```

Needs Node 22.18 or later, which runs `.ts` files directly. It writes `/output/entry.txt` (51 characters, 52 bytes, no trailing newline). The output is the same on every run, with no randomness and no network access. A guard throws if the text is outside 1–150 characters or only whitespace.
